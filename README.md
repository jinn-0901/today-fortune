# 오늘의 운세 · Today Fortune

전통 명리학의 만세력 계산을 이용해 사주 원국과 날짜별 일진을 확인하는 비회원 운세 웹사이트입니다.

## 현재 기능

- HTML, CSS, JavaScript 기반 정적 웹사이트
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 양력 및 음력 생년월일 입력
- 출생 시간을 입력하면 년주·월주·일주·시주 계산, 모르면 삼주만 표시
- 사주 원국의 천간·지지와 천간 십신 표시
- 네 기둥의 천간·지지 기준 오행 단순 집계
- 선택한 날짜의 일진 계산 및 출생 일간과의 오행 관계를 이용한 참고용 해석
- 회원가입·백엔드 없이 브라우저에서 계산
- GitHub Actions를 통한 GitHub Pages 자동 배포

## 계산 엔진

사주·음양력·절기 계산에는 MIT 라이선스의 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.8을 사용합니다. 라이브러리의 만세력 계산 결과를 화면에 표시하며, 사주 해석 문장은 사이트에서 정한 간단한 오행 관계 규칙으로 구성합니다.

현재 단계의 한계:
- 음력 윤달 입력은 아직 지원하지 않습니다. 음력 평달로 입력해 주세요.
- 출생 지역과 진태양시 보정은 아직 계산에 반영하지 않습니다.
- 오행 분포는 천간·지지의 기본 오행만 단순 집계합니다. 지장간, 월령, 왕쇠, 격국, 용신 등을 종합한 전문적인 균형 판단이 아닙니다.
- 대운·세운·월운, 궁합 및 상세 신살 해석은 아직 구현하지 않았습니다.
- 날짜별 해석은 전통 명리학의 오행 관계를 단순화한 참고용 콘텐츠이며 미래를 과학적으로 예측하지 않습니다.

## 배포

`main` 브랜치에 변경 사항을 push하면 `.github/workflows/deploy.yml`이 GitHub Pages 배포를 진행합니다.

배포 주소: https://jinn-0901.github.io/today-fortune/

## 개인정보

회원가입·백엔드·분석 추적을 사용하지 않습니다. 출생 정보는 브라우저에서 계산에만 사용하며 서버로 전송하거나 저장하지 않습니다. 계산 라이브러리는 jsDelivr CDN에서 불러오므로 계산 기능을 사용하려면 인터넷 연결이 필요합니다.
