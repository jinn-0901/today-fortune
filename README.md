# 오늘의 운세 · Today Fortune

동양적인 분위기의 비회원 운세 웹사이트입니다.

## 현재 구성

- HTML, CSS, JavaScript 기반의 정적 웹사이트
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 생년월일, 양력·음력, 출생 시간, 성별, 출생 지역 입력 UI
- 날짜별 일반 운세 예시
- 출생 정보는 서버로 전송하거나 저장하지 않음
- GitHub Actions를 통한 GitHub Pages 자동 배포

## 배포

`main` 브랜치에 변경 사항을 push하면 `.github/workflows/deploy.yml`이 GitHub Pages 배포를 진행합니다.

예상 배포 주소: https://jinn-0901.github.io/today-fortune/

## 다음 개발 단계

1. 절기·시간대·음력 윤달을 고려한 만세력 계산 엔진
2. 사주팔자, 오행, 십성 계산 및 검증
3. 대운·세운 계산
4. 계산 결과를 바탕으로 한 개인별 운세 풀이
5. 날짜별 개인 사주 운세와 궁합

> 현재 화면의 날짜별 운세 문구는 날짜에 따라 표시되는 일반 예시이며, 아직 개인 사주를 계산한 결과가 아닙니다. 실제 명리학 기반 풀이는 계산 엔진 구현 후 제공해야 합니다.

## 개인정보

현재 버전은 회원가입·백엔드·분석 추적을 사용하지 않습니다. 입력한 출생 정보는 브라우저 내에서 화면 안내에만 사용되며 저장되지 않습니다.
